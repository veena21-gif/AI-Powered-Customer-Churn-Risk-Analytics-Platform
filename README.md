## 📌 Project Overview

**Bank Customer Churn Prediction** is a Machine Learning and Deep Learning project designed to predict whether a bank customer is likely to **churn (leave the bank)** or **remain with the bank**.

The project analyzes customer demographic, financial, and behavioral information and applies multiple Machine Learning and Deep Learning algorithms to identify patterns associated with customer churn.

The complete project was developed from scratch using **Python and Google Colab**, covering the complete Machine Learning workflow from data preprocessing to model evaluation and prediction.

---

## 🎯 Objective

The main objective of this project is to:

- Analyze customer behavior and characteristics.
- Identify patterns associated with customer churn.
- Preprocess and transform customer data.
- Train multiple Machine Learning models.
- Build an Artificial Neural Network (ANN).
- Compare the performance of different models.
- Predict whether a customer is likely to churn.

---

## 🤖 Machine Learning Models

Six different classification models were implemented:

### 1. Logistic Regression

Used as a baseline classification algorithm for predicting customer churn.

### 2. K-Nearest Neighbors (KNN)

A distance-based classification algorithm that predicts customer churn based on similar customer records.

### 3. Random Forest

An ensemble learning algorithm that combines multiple decision trees to improve classification performance.

### 4. Naive Bayes

A probabilistic classification algorithm based on Bayes' theorem.

### 5. XGBoost

A gradient boosting algorithm that uses an ensemble of decision trees for powerful predictive performance.

### 6. Artificial Neural Network (ANN)

A Deep Learning model developed using **TensorFlow/Keras** to learn complex relationships between customer features and churn behavior.
